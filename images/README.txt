=== LOGOS DE EFECTECH ===

Coloca aquí tus archivos de logo con exactamente estos nombres:

  logo-dark.png
    → Logo para fondo CLARO (navbar blanca al inicio de la página)
    → Ejemplo: logo con texto oscuro (navy #1b2e4a) y fondo transparente
    → Tamaño recomendado: 300x80 px o similar proporción horizontal

  logo-white.png
    → Logo para fondo OSCURO (navbar al hacer scroll + footer)
    → Ejemplo: logo con texto blanco y fondo transparente
    → Tamaño recomendado: 300x80 px o similar proporción horizontal

IMPORTANTE:
  - Usa PNG con fondo transparente para que se vea "incrustado"
  - Si las imágenes no cargan, el sitio muestra un logo de texto de respaldo automáticamente
